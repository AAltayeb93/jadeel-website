لوحة تحكم موقع جديل

كيف تعدّل محتوى الموقع وصوره وألوانه بنفسك — دون أي خبرة برمجية.

المحتويات

١. كيف تفتح لوحة التحكم ٢. ربط المشروع ٣. تعديل النصوص (عربي وإنجليزي) ٤. تغيير الصور والشعار ٥. تغيير الألوان والتصميم ٦. إدارة المقالات ٧. معاينة التغييرات ونشرها ٨. أسئلة شائعة
الفكرة باختصار: الموقع مبني بطريقة تفصل «المحتوى» عن «التصميم». لوحة التحكم تعدّل ملفات المحتوى مباشرة، ثم تعيد بناء الموقع لتظهر التغييرات. لا حاجة لتعديل أي شيفرة برمجية.

١ كيف تفتح لوحة التحكم

تحتاج مرة واحدة إلى تشغيل أمرين من نافذة الطرفية (Terminal) داخل مجلد المشروع jadeel-website:

  1. لتشغيل اللوحة:  npm run panel
  2. افتح المتصفح على العنوان:  http://localhost:4400
مهم: افتح اللوحة في متصفح Google Chrome أو Microsoft Edge فقط، لأنهما يدعمان الحفظ المباشر في الملفات. (متصفح Safari لا يدعم هذه الميزة.)

ولكي ترى تغييراتك مباشرة أثناء التعديل، شغّل أيضًا خادم المعاينة في نافذة طرفية أخرى:

  1. npm run dev ثم افتح http://localhost:4321

٢ ربط المشروع

  1. اضغط زر «🔗 ربط مجلد المشروع» أعلى اللوحة.
  2. ستظهر نافذة لاختيار مجلد — اختر مجلد jadeel-website نفسه.
  3. سيطلب المتصفح السماح بالتعديل — اضغط تعديل أو Edit / Allow.
عند نجاح الربط ستتغيّر الحالة أعلى اليسار إلى «تم ربط المشروع ✓» وتظهر التبويبات الأربعة. تحتاج لتكرار هذه الخطوة في كل مرة تفتح فيها اللوحة من جديد.

٣ تعديل النصوص (عربي وإنجليزي)

من تبويب «📝 المحتوى»:

  1. اختر اللغة من الأعلى: العربية أو English.
  2. اختر الصفحة من القائمة الجانبية (الرئيسية، من نحن، الخدمات…).
  3. عدّل النصوص في الحقول. الحقول الطويلة تظهر كصناديق نص متعددة الأسطر.

القوائم القابلة للإضافة والحذف

بعض الأقسام عبارة عن قوائم (مثل: الخدمات، المنتجات، الأسئلة، المخرجات). فيها:

  • زر «＋ إضافة» لإضافة عنصر جديد.
  • علامة «✕» على كل عنصر لحذفه.

حقل «الأيقونة»

عند وجود حقل «الأيقونة»، اختر من القائمة المنسدلة، وستظهر معاينة صغيرة للأيقونة بجوارها.

لا تنسَ: بعد الانتهاء، اضغط زر «💾 حفظ كل التغييرات» بالأعلى. النصوص لا تُحفظ تلقائيًا.
عدّل النص نفسه في اللغتين (العربية ثم English) حتى يبقى الموقع متناسقًا بلغتيه.

٤ تغيير الصور والشعار

من تبويب «🖼️ الصور والشعار» تجد بطاقات للشعار وأيقونات المتصفح. اضغط «استبدال الصورة» واختر الصورة الجديدة.

٥ تغيير الألوان والتصميم

من تبويب «🎨 الألوان والتصميم»:

  • غيّر أي لون بالضغط على المربّع الملوّن، أو بكتابة كود اللون (مثل #11335e).
  • تظهر المعاينة المباشرة على الجانب فورًا.
  • يمكن تعديل درجة استدارة حواف الأزرار والبطاقات بالمؤشّرات.
  • زر «↩︎ استعادة الألوان الأصلية» يعيد ألوان هوية جديل المعتمدة.
انتبه للتباين: القاعدة في هوية جديل أن «الكحلي يحمل النص، والأخضر والذهبي يدعمانه». تجنّب الألوان الفاتحة جدًا للنصوص حتى تبقى مقروءة.
بعد تعديل الألوان اضغط «💾 حفظ كل التغييرات» لتُطبّق على الموقع.

٦ إدارة المقالات

من تبويب «📰 المقالات» تدير محتوى صفحة «المعرفة»:

  1. اضغط «＋ مقال جديد»، أو اختر مقالًا من القائمة لتعديله.
  2. اختر اللغة، واكتب اسم ملف بالإنجليزية (للمقال الجديد فقط) مثل my-article.
  3. املأ العنوان والوصف والتصنيف ومدة القراءة والتاريخ.
  4. اكتب نص المقال في الصندوق الكبير (يدعم تنسيق Markdown: ## عنوان، - نقطة).
  5. اضغط «💾 حفظ المقال». لحذف مقال استخدم زر «🗑 حذف المقال».
كل مقال يُحفظ مباشرة كملف مستقل. لإظهار مقال بلغتين، أنشئ نسختين: واحدة عربية وأخرى إنجليزية.

٧ معاينة التغييرات ونشرها

المعاينة المحلية

إذا كان npm run dev يعمل، افتح http://localhost:4321 وستظهر تغييرات النصوص والمقالات فورًا. لتغييرات الألوان أعد تحميل الصفحة.

النشر للموقع الحقيقي

  1. أوقف المعاينة، ثم نفّذ أمر البناء:  npm run build
  2. سيُنشأ مجلد dist/ — ارفع محتواه إلى الاستضافة (Netlify، Vercel، أو أي خادم).
في حال استخدمت استضافة مثل Netlify مربوطة بـ Git، سيكفي حفظ التغييرات ورفعها ليُعاد بناء الموقع تلقائيًا.

٨ أسئلة شائعة

هل أُفسد الموقع لو أخطأت؟

تعديل النصوص آمن تمامًا. تجنّب فقط حذف أقسام كاملة إن لم تكن متأكدًا. ويمكن دائمًا استعادة النسخة الأصلية إن كان المشروع على Git (git checkout).

زر الحفظ غير مفعّل؟

يتفعّل تلقائيًا بمجرد إجراء أي تعديل. إن بقي معطّلًا فأنت لم تربط المشروع بعد.

لم تظهر نافذة اختيار المجلد؟

تأكد أنك تستخدم Chrome أو Edge، وأنك فتحت اللوحة عبر http://localhost:4400 (لا بالنقر المزدوج على الملف).

التغييرات لا تظهر على الموقع؟

تأكد من الضغط على «حفظ كل التغييرات»، ثم أعد تحميل صفحة المعاينة، أو نفّذ npm run build للنشر.
